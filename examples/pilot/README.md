# Synthetic local pilot files

Use these files only with the `demo-inlectra` emulators.

- `questions.csv` covers `MC`, `MR`, `TF`, `NUM`, and `ESSAY` records.
- `roster.csv` matches eight fictional accounts named `student01@example.test` through `student08@example.test`.

Create those student accounts in separate browser profiles before you import `roster.csv`. The Canvas identifiers are fictional mapping values. They are not student IDs.

Do not replace these records with real student data for a local rehearsal.
